# Brazilian E-Commerce Exploratory Data Analysis

This project explores Brazil's e-commerce marketplace using the Brazilian E-Commerce Public Dataset by Olist. The analysis can be used to investigate order patterns, customers, products, payments, delivery performance, and reviews.

## Dataset

Obtain the dataset from its original source and place the CSV files in a local `data/` directory. Dataset files are not included in this repository.

## Setup

Create and activate a Python virtual environment, then install the common analysis packages:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Start Jupyter to open the project's analysis notebook:

```bash
jupyter notebook
```

## Areas to explore

- Order volume and trends over time
- Customer locations and geographic distribution
- Product categories and purchasing patterns
- Payment method usage
- Estimated versus actual delivery times
- Review scores and delivery experience

## Notes

Exploratory findings depend on data cleaning, filtering, and the dataset version used. They describe observed patterns and should not be interpreted as causal conclusions.
